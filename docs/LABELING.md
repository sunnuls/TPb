# Разметка зрения HIVE (YOLO)

Два этапа: детекция зон на столе/в лобби, затем классификация кропов карт.

## Stage 1 — детекция (`dataset/detect`)

Классы (порядок id 0…12):

| id | имя | что рисовать |
|----|-----|----------------|
| 0 | `card` | любая карта **лицом** и **рубашка** (закрытая) |
| 1 | `button_fold` | только **активная** кликабельная кнопка Fold |
| 2 | `button_check` | только активный Check |
| 3 | `button_call` | только активный Call |
| 4 | `button_raise` | только активный Raise / Bet |
| 5 | `button_allin` | только активный All-in |
| 6 | `pot` | зона **текста** с числом банка |
| 7 | `stack_own` | зона текста стека **героя** |
| 8 | `stack_enemy` | зона текста стека **оппонента** |
| 9 | `dealer_button` | фишка дилера |
| 10 | `seat_avatar` | аватар/слот игрока |
| 11 | `lobby_row` | строка стола в **лобби** |
| 12 | `join_button` | кнопка сесть / Join / Take seat |

Правила:

- `card` — один бокс на одну карту, включая рубашку. Не объединять две карты в один бокс.
- `button_*` — не размечать серые/недоступные кнопки. Только то, по чему можно тапнуть сейчас.
- `pot` / `stack_*` — бокс вокруг числа (с валютой/фишками, если они в одной плашке), не весь стол.
- `lobby_row` — вся строка стола (блайнды, игроки, стол), не иконка приложения.
- `join_button` — отдельный бокс кнопки посадки, даже если она внутри `lobby_row`.

Формат: YOLO txt, нормализованные `class x_center y_center width height`.

## Stage 2 — классификация карт (`dataset/cls`)

52 класса, имя = ранг + масть (латиница):

Ранги: `A K Q J T 9 8 7 6 5 4 3 2`  
Масти: `s` пики, `h` черви, `d` бубны, `c` трефы  

Полный набор: `As` … `Ks`, `Ah` … `Kh`, `Ad` … `Kd`, `Ac` … `Kc`.

Кропы режутся из боксов класса `card` (только **лицо**; рубашку в cls не класть).

Файл `crops_map.csv`:

```text
image,card_text
frame_0001.png,As
frame_0001.png,Kh
```

Несколько строк с одним `image` соответствуют картам **слева направо, сверху вниз**.

Имена файлов кропов: `{класс}_{индекс:04d}.jpg` в `dataset/cls/{train|val|test}/{класс}/`, например `dataset/cls/train/As/As_0003.jpg`.
